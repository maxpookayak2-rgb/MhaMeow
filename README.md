# บ้านอุ่นใจ — เว็บไซต์ช่วยหาบ้านให้น้องหมาและน้องแมว

## สถานะปัจจุบัน
มีส่วนติดต่อผู้ใช้สำหรับสมัครสมาชิก/เข้าสู่ระบบ ลงประกาศออนไลน์ และแชทระหว่างผู้ใช้ผ่าน Supabase แล้ว แต่ระบบออนไลน์จะทำงานจริงหลังตั้งค่าโปรเจกต์ Supabase ของคุณก่อนเท่านั้น

## เริ่มต้นใช้งานระบบออนไลน์
1. อ่านไฟล์ `README-SUPABASE.md`
2. สร้าง Supabase Project แล้วรัน `supabase-schema.sql` ใน SQL Editor
3. ใส่ Project URL และ Publishable/anon key ใน `supabase-config.js`
4. เปิดเว็บผ่าน local web server หรือ HTTPS hosting (ไม่แนะนำให้เปิดด้วย `file://`)
5. ทดสอบสมัครสมาชิกด้วยอีเมลของคุณ ยืนยันอีเมลถ้าระบบร้องขอ แล้วเข้าสู่ระบบ
6. สมัครอีกบัญชีหนึ่งในเบราว์เซอร์/อุปกรณ์อื่น ลงประกาศจากบัญชีนั้น แล้วทดสอบแชททั้งสองฝั่ง

## ฟังก์ชัน
- สมัครสมาชิกและเข้าสู่ระบบด้วยอีเมล/รหัสผ่าน
- ลงประกาศที่บันทึกในฐานข้อมูลออนไลน์
- ดูประกาศจากผู้ใช้คนอื่น
- เปิดบทสนทนาจากประกาศ และส่งข้อความแบบเรียลไทม์
- กล่องข้อความสำหรับเปิดบทสนทนาที่มีอยู่
- ค้นหาและกรองประกาศ รวมถึงแผนที่
- นโยบาย Row Level Security จำกัดสิทธิ์ข้อมูลตามเจ้าของและผู้ร่วมสนทนา

## ข้อจำกัดที่ยังเหลือ
- ประกาศตัวอย่าง 6 รายการยังเป็นข้อมูลสาธิต ไม่สามารถเริ่มแชทกับเจ้าของจริงได้
- ประกาศใหม่ยังไม่มีพิกัดแผนที่โดยอัตโนมัติ จึงแสดงในรายการแต่ไม่มีหมุดจนกว่าจะเพิ่มระบบเลือกตำแหน่ง
- รูปภาพเป็น URL ภายนอก ยังไม่มีระบบอัปโหลดรูป
- ยังไม่ได้ทดสอบกับ Supabase Project ของผู้ใช้ เพราะต้องใช้ Project URL/key ของโปรเจกต์นั้น
- ก่อนเปิดให้คนทั่วไปใช้ ควรทดสอบความปลอดภัยและการใช้งานจริงให้ครบ

## ความปลอดภัย
- ห้ามใส่ `service_role` หรือ secret key ในไฟล์เว็บ ให้ใช้เฉพาะ Publishable/anon key
- เปิดการยืนยันอีเมลและตั้งค่า Site URL/Redirect URLs ให้ตรงกับเว็บจริง
- ไม่ใส่รหัสผ่าน ที่อยู่บ้าน หรือข้อมูลการเงินในประกาศหรือแชท
